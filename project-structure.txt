## Steps to Rebuild and Deploy

### 1. Setup Environment

```bash
# Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Create Environment Variables

Create a `.env` file in the project root with the following:

```
FLASK_SECRET_KEY=your_secure_random_key
FIREBASE_PROJECT_ID=blazers-rovers-sample-database
FIREBASE_PRIVATE_KEY_ID=your_private_key_id
FIREBASE_PRIVATE_KEY=your_private_key
FIREBASE_CLIENT_EMAIL=your_client_email
FIREBASE_CLIENT_ID=your_client_id
FIREBASE_CLIENT_CERT_URL=your_client_cert_url
FIREBASE_DATABASE_URL=https://blazers-rovers-sample-database.firebaseio.com
FIREBASE_STORAGE_BUCKET=blazers-rovers-sample-database.appspot.com
```

Replace these placeholders with your actual Firebase credentials.

### 3. Set Up Firebase

1. Create a Firebase project (or use existing one)
2. Set up Firebase Authentication
3. Create Realtime Database with the following structure:
   - `Samples`: Collection of rock samples with their properties
   - `Dataset`: Collection of rock types with their characteristics

### 4. Run the Application Locally

```bash
flask run --debug
```

Visit `http://localhost:5000` in your browser.

### 5. Deployment Options

#### Option 1: Deploy to Heroku

1. Create a `Procfile`:
   ```
   web: gunicorn app:app
   ```

2. Add `gunicorn` to requirements.txt

3. Deploy:
   ```bash
   heroku create survivability-assessment-grid
   git push heroku main
   ```

#### Option 2: Deploy to Docker

1. Create a `Dockerfile`:
   ```Dockerfile
   FROM python:3.9-slim
   
   WORKDIR /app
   
   COPY requirements.txt .
   RUN pip install --no-cache-dir -r requirements.txt
   
   COPY . .
   
   CMD ["gunicorn", "--bind", "0.0.0.0:$PORT", "app:app"]
   ```

2. Build and run:
   ```bash
   docker build -t survivability-assessment-grid .
   docker run -p 5000:5000 -e PORT=5000 survivability-assessment-grid
   ```
